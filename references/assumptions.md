# 口径约定与待确认项

本文件记录所有影响金额的计算口径。**任一项未确认前，脚本必须以警告方式标注，不得静默取默认值。**

状态标记：`[已定]` 已确认 / `[待确认]` 需业务确认 / `[默认]` 暂用默认值，需复核

---

## A. 通用

| 项 | 状态 | 口径 | 影响 |
|---|---|---|---|
| 币种 | [已定] | 按仓/承运商原币核算，不跨币种汇总；汇总时分币种列示 | 直接决定金额 |
| 日期基准 | [待确认] | 出库费用按**出库完成时间**（`stock_delivered_at`）还是**建单时间**（`create_at`）归月 | 跨月单会移动 |
| 月结口径 | [待确认] | 自然月 vs 账单周期（如 26 日–次月 25 日） | 对账差额主因 |
| 取整 | [已定] | 单项费用保留 2 位；汇总不二次取整 | — |

## B. 计费重

| 项 | 状态 | 口径 |
|---|---|---|
| 体积重除数 | [待确认] | 英制 139 in³/lb、公制 5000 或 6000 cm³/kg，三者结果差 15%~20% |
| 尺寸进位 | [默认] | 向上取整到整英寸（UPS/FedEx 惯例） |
| 重量进位 | [默认] | 向上取整到整磅 |
| 实重来源 | [已定] | 用 `pkg_real_weight`（克），不用 `pkg_weight` |
| 计费重字段 | [已定] | 领星 `pkg_fee_weight` 实测 91% 为 0，不可用，必须自算 |

## C. 仓储费

| 项 | 状态 | 口径 |
|---|---|---|
| 计费单位 | [待确认] | 立方英尺/月、每件/月、每托/月 —— 决定整套算法量纲 |
| 体积取值 | [待确认] | 产品包装尺寸 vs 外箱尺寸 |
| 库龄起算 | [待确认] | 到仓日（入库流水日）vs 上架日 |
| 日结存口径 | [已定] | 今日快照 − Σ(之后流水)，逐日回推；可用量口径，不含次品/锁定 |
| 免仓期 | [待确认] | 是否有、多少天、是否按批次 |
| 旺季附加 | [待确认] | Q4 是否上浮、按比例还是按单价 |

## D. 运费

| 项 | 状态 | 口径 |
|---|---|---|
| 分区来源 | [已定] | 用收货邮编 + 发货仓邮编计算，不用承运商账单回填 |
| 燃油基准 | [待确认] | 按发货日所在周，还是按发票周期所属周 |
| 燃油计费基数 | [待确认] | 仅基础运费，还是含 AHS/Oversize（FedEx 与 UPS 不同） |
| AHS 判定 | [已定] | 长>48in / 次长>30in / 实重>50lb / 非瓦楞包装，任一即触发 |
| AHS 与 Oversize 叠加 | [待确认] | 超尺寸时是否同时收 AHS 与 Oversize |
| 住宅附加 | [待确认] | 是否已含在报价内（部分 3PL 一口价已包） |
| 退件费 | [已定] | 必须三方交叉：承运商轨迹 + 退货入库流水 + 退货单 |

## E. 已知数据缺口（跑数前必须处理）

1. **计费重缺失**：`pkg_fee_weight` 8,789 单中 8,031 单为 0（91.4%），全部自算。
2. **运费空值**：`logistics_freight` 有 15%（1,272 单）为空，对账时标记为"无实收值"，不计入差异。
3. **币种混杂**：USD 4,262 / CAD 3,189 / CNY 40 / GBP 38 / 空 1,260，必须按仓分币种。
4. **轨迹缺失**：`track_record` 基本为 None，判断"是否真退回"需另接 Track123 或承运商轨迹接口。
5. **费用无拆分**：领星只存运费总额，无基础/燃油/AHS 分项。**逐项核实必须有承运商账单**，否则只能核总额。
6. **流水起始**：仓位流水自领星启用 ERP 起才有记录，早于此的仓储费只能靠"期初盘点 + 月度进出"倒推。

## F. 结算完整性校验（每次跑数必查）

- 费率卡命中数必须恰好 1 张（0 张或多张即报错终止）
- 出库单必须 100% 匹配到实体仓，未匹配列入"未归类"清单
- 计费重为 0 或尺寸为 0 的订单单独列出，不参与计算
- 差异率超过阈值（默认 5%）的供应商优先输出，提示人工复核
